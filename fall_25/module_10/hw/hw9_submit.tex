\subsubsection*{Question 1 (a)}
\begin{flushleft}
    Representations based on clustering Suppose that we have a data set $X=\{x_1, \ldots, x_n\}$ consisting of points in a metric space $(\mathcal{X}, d)$. We cluster the data to get $k$ cluster centers $\mu_1, \ldots, \mu_k \in \mathcal{X}$. Here are a couple of the ways in which we can create a new representation of the data based on this clustering:
\end{flushleft}
\begin{flushleft}
    \textit{Represent each point by its cluster label, i.e., $\phi(x) = \arg \min_j d(x, \mu_j)$.}
\end{flushleft}
\begin{flushleft}
    In each of these cases, precisely specify the space in which the representation $\phi(x)$ lies (e.g. $\mathbb{R}^n$).

Note: When we have a hierarchical clustering, we can get more elaborate multi-scale representations.
\end{flushleft}

\subsubsection*{Solution 1 (a)}
The function $\phi(x)$ returns the index $j$ corresponding to the closest cluster center. Since there are $k$ cluster centers indexed from $1$ to $k$, the output is a single discrete integer.

Thus, the space is the discrete set of indices:
$$ \phi(x) \in \{1, 2, \ldots, k\} $$

\subsubsection*{\normalfont}{$\therefore \phi(x) \in \{1, \ldots, k\}$ (Discrete/Categorical Space)}

\subsubsection*{Graduate Level Explanation}
This representation is known as \textbf{Vector Quantization} or \textbf{Hard Assignment}. Mathematically, this maps the continuous input space $\mathcal{X}$ onto a discrete codebook. This effectively partitions the space into Voronoi regions, where every point in a region is mapped to the same integer label. This is a form of lossy compression; all local geometric information about $x$ relative to the center is discarded, retaining only the identity of the partition.

\subsubsection*{Learn Fast Explanation}
Think of this like a Zip Code. We don't care exactly where your house is (your exact coordinates); we just care which post office (cluster center) is closest to you. The result isn't a coordinate; it's just an ID number.

\subsection*{Solution 1}
\noindent\rule{\textwidth}{0.4pt}\\
\subsubsection*{Question 1 (b)}
\begin{flushleft}
    Representations based on clustering Suppose that we have a data set $X=\{x_1, \ldots, x_n\}$ consisting of points in a metric space $(\mathcal{X}, d)$. We cluster the data to get $k$ cluster centers $\mu_1, \ldots, \mu_k \in \mathcal{X}$. Here are a couple of the ways in which we can create a new representation of the data based on this clustering:
\end{flushleft}
\begin{flushleft}
    \textit{Represent each point by its distance to each of the centers, i.e., $\phi(x)_j = d(x, \mu_j)$.}
\end{flushleft}
\begin{flushleft}
    In each of these cases, precisely specify the space in which the representation $\phi(x)$ lies (e.g. $\mathbb{R}^n$).

Note: When we have a hierarchical clustering, we can get more elaborate multi-scale representations.
\end{flushleft}

\subsubsection*{Solution 1 (b)}
The representation $\phi(x)$ is constructed by calculating the distance from $x$ to every cluster center $\mu_1, \ldots, \mu_k$. This results in an ordered collection of $k$ real numbers.

Since distances in a metric space are non-negative real numbers, $\phi(x)$ is a vector in a $k$-dimensional Euclidean space (specifically the non-negative orthant).

\subsubsection*{\normalfont}{$\therefore \phi(x) \in \mathbb{R}^k$}

\subsubsection*{Graduate Level Explanation}
This representation embeds the data into a $k$-dimensional feature space based on similarity to prototypes. This is often called a \textbf{Radial Basis Function (RBF)} representation (if passed through a Gaussian kernel) or simply a distance-based embedding. Unlike 1(a), this preserves global geometry relative to the "landmarks" ($\mu_j$). If $k$ is large enough, we can often triangulate the exact position of $x$. This is a "soft" representation compared to the "hard" assignment of 1(a).

\subsubsection*{Learn Fast Explanation}
Think of this like GPS triangulation. Instead of just saying "You are in New York" (Label), this says "You are 10 miles from Tower A, 50 miles from Tower B, and 100 miles from Tower C." It results in a list of numbers (a vector) that describes your location much more precisely.

\subsection*{Solution 2}
\noindent\rule{\textwidth}{0.4pt}\\
\subsubsection*{Question 2}
\begin{flushleft}
    Determine if the following distance matrices are realizable in Euclidean space.
    \[
    D_1 = \begin{bmatrix}
    0 & 1 & 2 \\
    1 & 0 & 1 \\
    2 & 1 & 0
    \end{bmatrix}, \quad
    D_2 = \begin{bmatrix}
    0 & 1 & 3 \\
    1 & 0 & 1 \\
    3 & 1 & 0
    \end{bmatrix}
    \]
\end{flushleft}

\subsubsection*{Solution 2}

\textbf{Case 1: Matrix $D_1$} \\
Let the three points be $x_1, x_2, x_3$. From the matrix, the distances are:
$$d(x_1, x_2) = 1, \quad d(x_2, x_3) = 1, \quad d(x_1, x_3) = 2$$
We check the triangle inequality: $d(x_1, x_2) + d(x_2, x_3) = 1 + 1 = 2$.
Since $d(x_1, x_2) + d(x_2, x_3) = d(x_1, x_3)$, the triangle inequality holds with equality. This implies the points are collinear (lie on a single line).
We can construct these points in 1-dimensional Euclidean space ($\mathbb{R}^1$) by placing them on the number line:
$$ x_1 = 0, \quad x_2 = 1, \quad x_3 = 2 $$
Verification:
$|x_1 - x_2| = |0 - 1| = 1$ \checkmark \\
$|x_2 - x_3| = |1 - 2| = 1$ \checkmark \\
$|x_1 - x_3| = |0 - 2| = 2$ \checkmark

\vspace{1em}

\textbf{Case 2: Matrix $D_2$} \\
From the matrix, the distances are:
$$d(x_1, x_2) = 1, \quad d(x_2, x_3) = 1, \quad d(x_1, x_3) = 3$$
The triangle inequality states that for any three points in a metric space, the direct path must be less than or equal to any detour:
$$ d(x_1, x_3) \leq d(x_1, x_2) + d(x_2, x_3) $$
Substituting our values:
$$ 3 \leq 1 + 1 \implies 3 \leq 2 $$
This is False. The direct distance between $x_1$ and $x_3$ is larger than the sum of the steps via $x_2$, which is impossible in Euclidean geometry (or any valid metric space).

\subsubsection*{\normalfont}{$\therefore$ Matrix 1 is realizable ($x_1=0, x_2=1, x_3=2$). Matrix 2 is NOT realizable.}

\subsubsection*{Graduate Level Explanation}
Euclidean realizability requires two conditions. First, the distance matrix must define a valid \textbf{Metric Space}, satisfying the axioms of non-negativity, identity, symmetry, and the triangle inequality ($d(x,z) \le d(x,y) + d(y,z)$). Matrix $D_2$ fails this fundamental axiom, meaning it does not describe a geometry at all.

Second, if the metric axioms hold, the squared distance matrix $D^{(2)}$ must be transformable into a Positive Semi-Definite (PSD) Gram matrix $B$ via centering: $B = -\frac{1}{2}HD^{(2)}H$. If $B$ has negative eigenvalues, the distances form a valid metric but require non-Euclidean (e.g., hyperbolic) space. Matrix $D_1$ satisfies both; its Gram matrix has one positive eigenvalue (dimension 1) and zero negative eigenvalues.

\subsubsection*{Learn Fast Explanation}
Imagine walking.
For Matrix 1: You walk 1 mile to a store, then 1 more mile in the same direction to a park. You are now 2 miles from home. This makes sense.
For Matrix 2: You walk 1 mile to a store, then 1 mile to a park, but somehow you end up 3 miles from home. That's magic, not math. You can't end up further away than the total distance you walked.

\noindent\rule{\textwidth}{0.4pt}\\
\subsubsection*{Question 3 (a)}
\begin{flushleft}
    Consider the following three points in $\mathbb{R}^3$:

\[
x = \begin{bmatrix}1 \\ 2 \\ 3\end{bmatrix}, \quad
y = \begin{bmatrix}-1 \\ 0 \\ 1\end{bmatrix}, \quad
z = \begin{bmatrix}0 \\ -2 \\ -4\end{bmatrix}
\]

\end{flushleft}
\begin{flushleft}
    Let $D$ be the matrix of squared interpoint distances. What is $D$?
    
\end{flushleft}

\subsubsection*{Solution 3 (a)}
Let the points be denoted as vectors:
$x_1 = [1, 2, 3]^T$, $x_2 = [-1, 0, 1]^T$, $x_3 = [0, -2, -4]^T$.

The matrix $D$ consists of squared Euclidean distances $D_{ij} = ||x_i - x_j||^2$.
Calculations:
\begin{align*}
    D_{11} &= D_{22} = D_{33} = 0 \\
    D_{12} &= ||x_1 - x_2||^2 = (1 - (-1))^2 + (2 - 0)^2 + (3 - 1)^2 = 2^2 + 2^2 + 2^2 = 4+4+4 = 12 \\
    D_{13} &= ||x_1 - x_3||^2 = (1 - 0)^2 + (2 - (-2))^2 + (3 - (-4))^2 = 1^2 + 4^2 + 7^2 = 1+16+49 = 66 \\
    D_{23} &= ||x_2 - x_3||^2 = (-1 - 0)^2 + (0 - (-2))^2 + (1 - (-4))^2 = (-1)^2 + 2^2 + 5^2 = 1+4+25 = 30
\end{align*}
By symmetry $D_{ij} = D_{ji}$.

\subsubsection*{\normalfont}{$\therefore D = \begin{bmatrix} 0 & 12 & 66 \\ 12 & 0 & 30 \\ 66 & 30 & 0 \end{bmatrix}$}

\subsubsection*{Graduate Level Explanation}
This matrix represents the raw geometry of the point cloud invariant to rotation and translation. However, $D$ itself is not positive semi-definite (PSD). In spectral clustering and MDS, we typically operate on affinity or Gram matrices which are PSD. The transformation from $D$ (squared distances) to a Gram matrix involves a specific geometric mapping known as "Double Centering."

\subsubsection*{Learn Fast Explanation}
We are just using the Pythagorean theorem here. $a^2 + b^2 + c^2 = distance^2$. The matrix is symmetric because the distance from me to you is the same as the distance from you to me.

\noindent\rule{\textwidth}{0.4pt}\\
\subsubsection*{Question 3 (b)}
\begin{flushleft}
    Consider the following three points in $\mathbb{R}^3$:

\[
x = \begin{bmatrix}1 \\ 2 \\ 3\end{bmatrix}, \quad
y = \begin{bmatrix}-1 \\ 0 \\ 1\end{bmatrix}, \quad
z = \begin{bmatrix}0 \\ -2 \\ -4\end{bmatrix}
\]

\end{flushleft}
\begin{flushleft}

What is the appropriate $H$ matrix for this situation?
  
\end{flushleft}

\subsubsection*{Solution 3 (b)}
$H$ is the centering matrix defined as $H = I - \frac{1}{n}\mathbf{1}\mathbf{1}^T$, where $I$ is the identity matrix, $n$ is the number of points, and $\mathbf{1}$ is a column vector of ones.
Here, $n=3$.

$$ H = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} - \frac{1}{3}\begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}\begin{bmatrix} 1 & 1 & 1 \end{bmatrix} $$

$$ H = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} - \begin{bmatrix} 1/3 & 1/3 & 1/3 \\ 1/3 & 1/3 & 1/3 \\ 1/3 & 1/3 & 1/3 \end{bmatrix} $$

\subsubsection*{\normalfont}{$\therefore H = \begin{bmatrix} 2/3 & -1/3 & -1/3 \\ -1/3 & 2/3 & -1/3 \\ -1/3 & -1/3 & 2/3 \end{bmatrix}$}

\subsubsection*{Graduate Level Explanation}
The matrix $H$ is an idempotent projection matrix ($H^2 = H$). Geometrically, it projects any vector onto the subspace orthogonal to the vector $\mathbf{1} = [1, 1, 1]^T$. When applied to a data matrix, it removes the mean (centers the data). When applied to a distance matrix (as in MDS), it effectively places the origin at the geometric centroid of the points.

\subsubsection*{Learn Fast Explanation}
$H$ stands for "Centering." Think of it as a tool that shifts the camera so that the "average" of all points is exactly at $(0,0,0)$.

\subsubsection*{Question 3 (c)}
\begin{flushleft}
    Consider the following three points in $\mathbb{R}^3$:

\[
x = \begin{bmatrix}1 \\ 2 \\ 3\end{bmatrix}, \quad
y = \begin{bmatrix}-1 \\ 0 \\ 1\end{bmatrix}, \quad
z = \begin{bmatrix}0 \\ -2 \\ -4\end{bmatrix}

\begin{flushleft}

Compute $-\frac{1}{2}HDH$. What do you get?
    
\end{flushleft}

\subsubsection*{Solution 3 (c)}
This operation converts the squared distance matrix into the centered Gram matrix $B$.
$$ B = -\frac{1}{2} H D H $$
Performing the matrix multiplication:
1. $DH = \begin{bmatrix} 0 & 12 & 66 \\ 12 & 0 & 30 \\ 66 & 30 & 0 \end{bmatrix} \begin{bmatrix} 2/3 & -1/3 & -1/3 \\ -1/3 & 2/3 & -1/3 \\ -1/3 & -1/3 & 2/3 \end{bmatrix} = \begin{bmatrix} -26 & -14 & 40 \\ -2 & 14 & -12 \\ 34 & -12 & -22 \end{bmatrix}$

2. $H(DH) = \begin{bmatrix} 2/3 & -1/3 & -1/3 \\ -1/3 & 2/3 & -1/3 \\ -1/3 & -1/3 & 2/3 \end{bmatrix} \begin{bmatrix} -26 & -14 & 40 \\ -2 & 14 & -12 \\ 34 & -12 & -22 \end{bmatrix} = \begin{bmatrix} -28 & -4 & 32 \\ -4 & -4 & 8 \\ 32 & 8 & -40 \end{bmatrix}$

3. Multiply by $-\frac{1}{2}$:
$$ B = -\frac{1}{2} \begin{bmatrix} -28 & -4 & 32 \\ -4 & -4 & 8 \\ 32 & 8 & -40 \end{bmatrix} $$

\subsubsection*{\normalfont}{$\therefore \begin{bmatrix} 14 & 2 & -16 \\ 2 & 2 & -4 \\ -16 & -4 & 20 \end{bmatrix}$}

\subsubsection*{Graduate Level Explanation}
This result is the Gram Matrix $B$ where $B_{ij} = \langle x_i - \mu, x_j - \mu \rangle$.
We can verify this via the Law of Cosines relation used in MDS:
$x_i^T x_j = -\frac{1}{2} (d_{ij}^2 - d_{i \cdot}^2 - d_{\cdot j}^2 + d_{\cdot \cdot}^2)$. The matrix operations $HDH$ perform this "double centering" automatically, subtracting row means and column means from the distance matrix to recover the inner products.

\subsubsection*{Learn Fast Explanation}
We just converted "relative distances" (how far points are from each other) into "absolute coordinates" (how far points are from the center). The result tells us the dot product between every pair of points.

\begin{flushleft}
    Consider the following three points in $\mathbb{R}^3$:

\[
x = \begin{bmatrix}1 \\ 2 \\ 3\end{bmatrix}, \quad
y = \begin{bmatrix}-1 \\ 0 \\ 1\end{bmatrix}, \quad

Is the answer in (c) the correct Gram matrix for the data?
    
\end{flushleft}

\subsubsection*{Solution 3 (d)}
Yes.
The definition of the Gram matrix for a set of vectors $X$ is $G = XX^T$.
Let us calculate $XX^T$ directly for the provided points:
$$ x = \begin{bmatrix}1 \\ 2 \\ 3\end{bmatrix}, y = \begin{bmatrix}-1 \\ 0 \\ 1\end{bmatrix}, z = \begin{bmatrix}0 \\ -2 \\ -4\end{bmatrix} $$
$$ X = \begin{bmatrix} 1 & 2 & 3 \\ -1 & 0 & 1 \\ 0 & -2 & -4 \end{bmatrix} $$
The dot products are:
$x \cdot x = 1^2 + 2^2 + 3^2 = 14$ \\
$x \cdot y = -1 + 0 + 3 = 2$ \\
$x \cdot z = 0 - 4 - 12 = -16$ \\
... and so on.

The result matches the matrix from part (c) exactly.
Note: The operation in (c) produces the Gram matrix of the \textit{centered} data. Since the mean of the original points is $\vec{0}$, the centered Gram matrix and the original Gram matrix are identical.

\subsubsection*{\normalfont}{$\therefore$ Yes, it matches $X X^T$ exactly.}

\subsubsection*{Graduate Level Explanation}
Usually, Classical MDS recovers the Gram matrix of the centered coordinates. If the original data had a non-zero mean $\mu$, the result of (c) would be $(X - \mathbf{1}\mu^T)(X - \mathbf{1}\mu^T)^T$, while the "true" Gram matrix would be $XX^T$. They would differ by rank-1 updates related to the mean. However, in this specific problem instance, $\sum x_i = \vec{0}$, so the data manifold is already centered at the origin, making the two matrices equivalent.

\subsubsection*{Learn Fast Explanation}
Yes. We proved it by doing it the hard way (using $H$ and $D$) and the easy way (just multiplying the point vectors directly). We got the same numbers both times.

\subsubsection*{Question 4 (a)}
\begin{flushleft}
    A set of $n$ points in $\mathbb{R}^d$ is orthonormal: that is, each point has unit length and the points are orthogonal to one another.

\end{flushleft}
\begin{flushleft}
    What is the Gram matrix for this data? Be sure to specify its dimension clearly.
    
\end{flushleft}

\subsubsection*{Solution 4 (a)}
Let the points be vectors $x_1, \ldots, x_n$.
The definition of \textbf{orthonormal} is:
1. Orthogonal: The dot product of distinct vectors is zero ($x_i^T x_j = 0$ for $i \neq j$).
2. Normal: The length of each vector is one ($x_i^T x_i = ||x_i||^2 = 1$).

The Gram matrix $G$ is defined as $G_{ij} = x_i^T x_j$.
Applying the definition:
\begin{itemize}
    \item Diagonal entries ($i=j$): $G_{ii} = x_i^T x_i = 1$.
    \item Off-diagonal entries ($i \neq j$): $G_{ij} = x_i^T x_j = 0$.
\end{itemize}
Thus, $G$ is the Identity matrix.

\subsubsection*{\normalfont}{$\therefore G = I_n$ (The $n \times n$ Identity Matrix)}

\subsection*{Solution 4}
\noindent\rule{\textwidth}{0.4pt}\\
\subsubsection*{Question 4 (b)}
\begin{flushleft}
    A set of $n$ points in $\mathbb{R}^d$ is orthonormal: that is, each point has unit length and the points are orthogonal to one another.

\end{flushleft}
\begin{flushleft}

What is the matrix of squared interpoint distances?
  
\end{flushleft}


\subsubsection*{Solution 4 (b)}
The squared Euclidean distance between two vectors $x_i$ and $x_j$ is given by the expansion:
$$ ||x_i - x_j||^2 = (x_i - x_j)^T (x_i - x_j) $$
$$ = x_i^T x_i - 2x_i^T x_j + x_j^T x_j $$
Substitute the orthonormal properties from part (a):
\begin{itemize}
    \item If $i = j$: $||x_i - x_i||^2 = 0$.
    \item If $i \neq j$: $||x_i - x_j||^2 = 1 - 2(0) + 1 = 2$.
\end{itemize}
Therefore, the squared distance matrix $D$ has $0$ on the diagonal and $2$ everywhere else.

\subsubsection*{\normalfont}{$\therefore D = 2(\mathbf{1}\mathbf{1}^T - I) = \begin{bmatrix} 0 & 2 & \dots & 2 \\ 2 & 0 & \dots & 2 \\ \vdots & \vdots & \ddots & \vdots \\ 2 & 2 & \dots & 0 \end{bmatrix}$}

\subsubsection*{Graduate Level Explanation}
This geometry describes a \textbf{Regular Simplex}. The points form the vertices of a generalized equilateral triangle (or tetrahedron) in high-dimensional space. Every point is equidistant from every other point. This is a common initialization state in high-dimensional spaces (e.g., "one-hot" encoding of words in NLP often approximates this geometry before training embeddings).

\subsubsection*{Learn Fast Explanation}
Imagine the corners of a cube (but in higher dimensions). They are all "unit length" away from the center. The distance between any two distinct corners (that are connected by an edge) is exactly $\sqrt{2}$, so the squared distance is 2.

\subsubsection*{Solution 5 (a)}

\subsubsection*{Python Code for d=10}
\begin{lstlisting}
import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import euclidean_distances

def cmdscale(D_squared, k=2):
    """
    Classical Multidimensional Scaling (cMDS)
    Parameters:
    D_squared (n x n): Matrix of squared interpoint distances
    k (int): Target dimension
    
    Returns:
    Y (n x k): Projected coordinates
    """
    n = D_squared.shape[0]
    
    # 1. Compute Centering Matrix H
    H = np.eye(n) - (1/n) * np.ones((n, n))
    
    # 2. Compute B = -1/2 * H * D_squared * H
    B = -0.5 * H @ D_squared @ H
    
    # 3. Spectral Decomposition
    # np.linalg.eigh returns eigenvalues in ASCENDING order
    evals, evecs = np.linalg.eigh(B)
    
    # Sort DESCENDING (Flip arrays)
    idx = np.argsort(evals)[::-1]
    evals = evals[idx]
    evecs = evecs[:, idx]
    
    # 4. Zero out negative eigenvalues (for non-Euclidean noise)
    # This matches Step 3 of your lecture notes
    evals_pos = np.maximum(evals, 0)

# --- 2. MDS Function ---
def cmdscale(D, k=2):
    """
    Classical MDS: Projects n points into k-dimensional space.
    """
    n = D.shape[0]
    H = np.eye(n) - (1/n) * np.ones((n, n))
    B = -0.5 * H @ D @ H
    
    evals, evecs = np.linalg.eigh(B)
    
    # Sort descending
    idx = np.argsort(evals)[::-1]
    evals = evals[idx]
    evecs = evecs[:, idx]
    
    # Project
    w_pos = np.maximum(evals, 0)
    Y = evecs @ np.diag(np.sqrt(w_pos))
    return Y[:, :k]

# --- 3. Rotation Function (The Homework Requirement) ---
def rotate_data(X, angle_degrees):
    """
    Rotates 2D data X by angle_degrees (counter-clockwise).
    """
    theta = np.radians(angle_degrees)
    c, s = np.cos(theta), np.sin(theta)
    
    # Rotation Matrix
    R = np.array([[c, -s], 
                  [s,  c]])
    
    # Apply R to every point. 
    # Since X is (N x 2), we compute (R @ X.T).T or simply X @ R.T
    return X @ R.T

# --- 4. Plotting Function ---
def plot_map(X, labels, title="MDS Map"):
    plt.figure(figsize=(8, 8))
    plt.scatter(X[:, 0], X[:, 1], c='red', marker='o')
    
    for i, txt in enumerate(labels):
        plt.annotate(txt, (X[i, 0], X[i, 1]), 
                     xytext=(5, 5), textcoords='offset points')
        
    plt.title(title)
    plt.grid(True)
    plt.axis('equal')
    plt.show()

# --- Execution ---
